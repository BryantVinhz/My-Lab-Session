# Assignment 2
- The steps I followed to create a Github Page are:
    - Firstly, I created a github repository
    - Secondly, I added a file named index.html to support the creation of the GitHub Page
    - Thirdly, I went to Settings in the repository, then selected Pages, in here I chose:
        - Branch: main
        - Folder: / root
    - Next, I saved the settings
    - After that, I clicked on the "Actions" tab to monitor the deployment process
    - Finally, I returned to "Settings", went to "Pages", and clicked on "Visit site" to view the published website
