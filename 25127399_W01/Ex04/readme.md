- The steps I followed to create a Group Repository are:
    - Firstly, I created a private repository on GitHub for my group
    - Secondly, I went to "Settings" and selected "Collaborations" to invite all group members
    - In here, I clicked "Add people" and search group members by username, full name, or email to add them to the repository
    - Finally, all members need only accept the invitations to access to the repository
